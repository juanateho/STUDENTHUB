## 💡 Descripción del Proyecto

**STUDENTHUB** es una aplicación móvil diseñada para simplificar y centralizar la vida académica de los estudiantes. Nuestra misión es proporcionar una herramienta eficiente que ayude a organizar horarios, gestionar tareas, hacer seguimiento a las calificaciones y facilitar la comunicación, todo en un solo lugar.

## ✨ Características Principales

STUDENTHUB ofrece una gama de funcionalidades clave para mejorar la productividad estudiantil:

* **Gestión de Horarios:** Visualización clara del calendario de clases con recordatorios automáticos.
* **Seguimiento de Tareas y Exámenes:** Lista de pendientes con fechas límite, prioridades y notificaciones.
* **Registro de Calificaciones:** Herramienta para ingresar notas y calcular promedios por asignatura.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando el ecosistema de Android moderno:

* **Lenguaje de Programación:** [Kotlin](https://kotlinlang.org/)
* **Plataforma:** [Android SDK](https://developer.android.com/)
* **Arquitectura:** MVVM
* **Persistencia de Datos:** Firebase Firestore)

## 🚀 Instalación y Configuración (Para Desarrolladores)

Sigue estos pasos para tener una copia local del proyecto ejecutándose en tu máquina:

### Requisitos Previos

* [Android Studio](https://developer.android.com/studio) (Versión 2023.2 o superior recomendada)
* [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/)
* Dispositivo físico o emulador con Android 8.0 (API 26) o superior.

### Pasos de Instalación

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/juanateho/STUDENTHUB.git](https://github.com/juanateho/STUDENTHUB.git)
    ```

2.  **Abrir el proyecto:**
    Abre Android Studio y selecciona `Open` (Abrir), luego navega a la carpeta `STUDENTHUB` que acabas de clonar.

3.  **Sincronizar Gradle:**
    Android Studio debería sincronizar automáticamente los archivos de Gradle. Si no es así, haz clic en el icono de "Sync Project with Gradle Files" (Sincronizar proyecto con archivos Gradle).

4.  **Configurar dependencias (si aplica):**
    Si el proyecto utiliza servicios externos (como Firebase), asegúrate de agregar el archivo `google-services.json` en la carpeta `app/`.

5.  **Ejecutar la aplicación:**
    Selecciona un emulador o un dispositivo conectado y haz clic en el botón `Run` (Ejecutar) (el ícono de flecha verde).
